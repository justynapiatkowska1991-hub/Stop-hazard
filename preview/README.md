# STOP HAZARD

Mobilny prototyp panelu ochrony.

## Moduły
- Start i status ochrony
- Statystyki
- Ostatnia aktywność
- Własne blokady domen
- Aktywność
- Ustawienia
- Poziom bezpieczeństwa
- Prywatność
- Pomoc
- Ekran blokady
- PWA/offline

## Ważne
Interfejs GitHub Pages jest demonstracją. Rzeczywiste blokowanie ruchu całego urządzenia wymaga natywnej implementacji Androida, np. mechanizmu VPN/DNS oraz odpowiednich uprawnień. Sama strona WWW nie może samodzielnie filtrować całego ruchu urządzenia.
